# Unity ML-Agents Toolkit

[![docs badge](https://img.shields.io/badge/docs-reference-blue.svg)](https://docs.unity3d.com/Packages/com.unity.ml-agents@latest)

[![license badge](https://img.shields.io/badge/license-Apache--2.0-green.svg)](LICENSE.md)

([latest release](https://github.com/Unity-Technologies/ml-agents/releases/tag/latest_release)) ([all releases](https://github.com/Unity-Technologies/ml-agents/releases))

The **Unity Machine Learning Agents Toolkit** (ML-Agents) is an open-source project that enables games and simulations to serve as environments for training intelligent agents.

## Documentation

The [ML-Agents package documentation](https://docs.unity3d.com/Packages/com.unity.ml-agents@latest) is the primary documentation for ML-Agents. It includes installation instructions, version compatibility, features, tutorials, API references, and how to [cite ML-Agents in your research](com.unity.ml-agents/Documentation~/Cite-ML-Agents.md).

## Get started

To install ML-Agents and check which Unity and Python versions are compatible, refer to [Install the ML-Agents Toolkit](https://docs.unity3d.com/Packages/com.unity.ml-agents@latest/index.html?subfolder=/manual/Installation.html).

## Contribute

To contribute, refer to [Contribute to ML-Agents](com.unity.ml-agents/Documentation~/CONTRIBUTING.md) and the [code of conduct](CODE_OF_CONDUCT.md).

## Get help and give feedback

- For installation and setup problems, or discussions about how to set up or train your agents, create a thread on the [Unity ML-Agents discussion forum](https://discussions.unity.com/tag/ml-agents).
- For other problems or feature requests, [submit a GitHub issue](https://github.com/Unity-Technologies/ml-agents/issues).

For more community resources and information about privacy and in-editor analytics, refer to the [ML-Agents package documentation home page](https://docs.unity3d.com/Packages/com.unity.ml-agents@latest/index.html).
